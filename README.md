# SUX

SUX is a low-budget meme token experiment: an $80 challenge, public receipts, a fixed target supply of 1,000,000,000 SUX with 2 decimals, and no profit promises.

## What the first $10 is for

| Item | Budget | Implementation |
| --- | ---: | --- |
| Fresh wallet | $3 | Create a new wallet used only for SUX. Publish the wallet address. |
| Test transaction | $2 | Send a tiny test transaction and save the explorer link. |
| Launch fees | $3 | Reserve for token creation, metadata, signatures, and retries. |
| Emergency | $2 | Keep untouched unless a launch step fails. If unused, move to bounty budget. |

## $0 website

This repo is a static GitHub Pages-ready site.

Canonical site URL: `https://sux-project.github.io/SUX/`
Repository: `https://github.com/SUX-Project/SUX`

1. Push this folder to `https://github.com/SUX-Project/SUX`.
2. In GitHub, open `Settings -> Pages`.
3. Set `Source` to `Deploy from a branch`.
4. Choose the `main` branch and `/root`.
5. Save. The page will publish at `https://sux-project.github.io/SUX/`.
